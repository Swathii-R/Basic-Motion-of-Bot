# Basic Motion of Bot

## Overview

This repository documents the basic movements of a robot using simple programming commands.

**Topics Covered**

- Forward Movement
- Backward Movement
- Left Turn
- Right Turn
- Stop Motion

**Learning Outcomes**

- Basic Movements: Learned how to control the basic movements of a robot.
- Directional Control: Understood how to turn the robot left and right.
- Motion Programming: Practiced writing simple programs to control robot movement.

**Technologies Used**

- Python Programming
- Robot Simulation / Robot Hardware

**Conclusion**

This project helped me understand the fundamentals of robot motion and basic movement control using programming.
